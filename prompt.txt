PROMPT 1
Problem Statement: Write a 2D graphics editor using * and _.
Write functions to draw a circle, rectangle, line, and triangle.
You should be able to:
* add objects to the picture
* delete objects from the picture
* modify objects in the picture
Use a 2D array of characters to store the picture.
Write a function to display the picture.

RESPONSE 1
Suggested approach:

1. Use a 2D character array as a canvas.
2. Initialize the canvas with '_' characters.
3. Use '*' characters to draw shapes.
4. Implement functions:
   * drawLine()
   * drawRectangle()
   * drawCircle()
   * drawTriangle()
5. Store all shapes in an array of structures.
6. Implement:
   * Add Object
   * Delete Object
   * Modify Object
7. Redraw the canvas whenever an object is added, deleted, or modified.
8. Display the canvas using nested loops.


PROMPT 2
Explain the problem and logic.

RESPONSE 2
The graphics editor uses a 2D character array as a drawing surface.
Each shape is represented by a structure containing:
* Shape type
* Coordinates
* Radius (for circles)
Objects are stored in an array.
When the user chooses to display the picture:
1. The canvas is cleared.
2. Every stored object is drawn again.
3. The completed picture is displayed.
This allows objects to be modified or deleted easily.
